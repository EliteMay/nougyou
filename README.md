# 2050年のAI農業 — グループ発表準備

環境・仕事・食料の安定・消費者の安心の4観点を統一した方針で調査し、発表へつなげるための共有サイトです。

- 公開予定URL: https://elitemay.github.io/nougyou/ （GitHub Pages設定後に有効。公開確認が済むまでは公開済みと扱わない。）
- [サイト本体・現在の方針と変更履歴](index.html)

## 更新方法

`index.html` が現行方針と変更履歴の正本です。変更時は該当する現在の方針、担当の到達点、更新日を直し、変更理由を履歴に追記してください。未承認の提案と確定事項、研究結果と考察を区別します。公開リポジトリなので個人情報は掲載しません。

## 初回公開

[Settings → Pages](https://github.com/EliteMay/nougyou/settings/pages) で Source を Deploy from a branch、Branch を main、Folder を /(root) に設定して Save。公開後は上記URLで4つの担当と変更履歴が表示されることを確認してください。外部ライブラリやビルドは不要です。
